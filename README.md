## Lo que hago

**Ingeniería civil**, desde sus planos (o desde fotos y medidas, si se trata de remodelar):

- Cantidades de obra, con la fórmula y el plano de origen de cada cifra.
- Presupuesto con análisis de precios unitarios (APU).
- Modelado BIM y juego de planos.
- Revisión documental NSR-10: cada hallazgo con su numeral y su página.
- Hidrología y análisis de datos: lluvias, caudales y perfiles hidráulicos.

**Software**, de punta a punta:

- Aplicaciones web para llevar una obra, una finca o un negocio pequeño.
- Asistentes de IA conectados a sus propios datos.
- Apps Android y páginas web.
